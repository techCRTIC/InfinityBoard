Features

Lienzo Infinito

Infinite Canvas

Instalación

Installation

git clone https://github.com/techCRTIC/InfinityBoard.git
cd InfinityBoard
npm install
npm run dev

Configura tu API Key de Gemini en Settings (⚙️) para activar la IA.

Configure your Gemini API Key in Settings (⚙️) to enable AI features.
